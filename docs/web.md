# Web 控制台

```bash
fishkernel web AGENT --host 127.0.0.1 --port 8787 --token '自定义令牌'
```

默认本机访问。浏览器可首次用 `/?token=...` 打开；页面将令牌保存到当前会话，
后续请求使用 X-Fish-Token，并从地址栏移除 token。403 时可重新输入。

控制台显示事件、任务、用量、思考设置和插件异常数量；支持消息、暂停、恢复、
唤醒、停止和交接。消息提交失败会保留输入框，重复点击不会重复发起同一请求。
只有一个轮询链；控制动作要求尽快刷新，不再额外启动轮询链。

快照返回 next_cursor 和 has_more，增量超过 400 条时从最早未读页顺序拉取；
首次打开只显示近期事件。DOM 最多保留 2000 条，后端存档不受影响。
HTTP 接口见 `web.py`，不直接写事件日志。
