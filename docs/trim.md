# 活动事件归档

```bash
fishkernel trim AGENT --dry-run
fishkernel trim AGENT --yes
```

trim 将已被压缩摘要覆盖的旧事件移到归档文件，保留当前摘要、完整调用单元及后续事件。
不重编号 seq，不删除人格、长期记忆或历史归档。执行时必须取得实例锁，因此要先停内核。
dry-run 仅预览；正式执行在锁内重新读取和校验计划，不使用过期预览直接写盘。

未完成的压缩事务会阻止归档；已经 end/abort 的事务不会永久阻塞。
归档前同步独立 usage 账本，累计用量和已定价费用不因活动日志变短而减少。
插件订阅只保证活动事件范围，归档后更老的事件需从归档文件读取。
