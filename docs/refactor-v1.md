# Kernel v1 改造与验收

范围：Linux；通用 OpenAI Chat Completions 与任意模型 ID；独立进程插件；
中断工具等待，不取消在途模型请求；保留旧 Agent 的人格、记忆和上下文。
不适配 Napcat，不迁移个人工具或旧 hook，不改写 Git 历史。

## 实施阶段

- [ ] 数据完整性：实例锁、事件读取、消息提交、记忆水位、压缩事务、trim。
- [ ] 模型与上下文：工具配对、图片、摘要分块、配置、思考、错误与用量。
- [ ] 运行协调：消息唤醒、取消、独立任务监督、Linux 平台边界。
- [ ] 插件：协议、进程监督、动态工具、消息输入、管理接口与示例。
- [ ] 兼容迁移：保留 Agent 状态，移除旧 hook，不执行旧工具。
- [ ] 界面与工程：TUI、Web、文档、脚本、Linux CI 与组合验收。

中间提交仅用于审查；升级真实存档须完成组合验收。记忆接管与旧 hook 停用
在同一版本生效，不允许旧同步脚本和新记忆投影同时写入。

## 数据契约

事件单写者；输入持久化后 ACK、提交事件后确认消费；重复输入 ID 去重。
记忆 checkpoint 保存内容与已应用 seq，文件投影可恢复。压缩提交记录先于
可见摘要投影。迁移不重编号 seq、不重放外部副作用、不删除未知文件。

工具终态区分成功、失败、执行前中断和结果不确定。取消 wait_job 不杀后台任务。
新输入在生成期间持久排队；模型返回后先为未执行调用补齐中断结果，再处理输入。

## 验证

纯逻辑与合成存档测试可跨平台运行；文件锁、进程组、信号、PTY、插件进程和
崩溃恢复必须在 Linux 真实执行。平台不可用时明确标记未验收，不用模拟测试替代。
测试数据不含真实凭据或个人记忆。私有样例仅在仓库外的副本上检查。
