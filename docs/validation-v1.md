## 核心组合验证

- 模型生成期间接收新输入，保留响应，为未执行工具补齐中断结果。
- 插件输入中断 sleep / wait_job；正常负载下，从插件发送到退出等待小于 500 ms。
- 前台插件调用支持取消；wait_job 中断后后台任务仍运行。
- 插件异常退出、坏协议、调用超时、队列满及坏重载配置得到隔离；子进程随故障清理。
- 模型用 plugin_manage 启用插件，下一轮获得动态工具并完成调用；旧世代调用不会派发给新实例。
- 后台任务在原管理进程退出后仍输出并被接管；输出超限有明确终态。
- 真实 SIGKILL 恢复和交接测试验证事件序号与单写者；mock 交接保持离线模式。
- 通用模型 ID、输出参数和思考映射通过真实 SDK → 本机 HTTP 兼容服务验证；400 不重复请求。
- 记忆 checkpoint、压缩提交、工具配对、独立 usage 账本与 trim 防覆盖通过故障注入和回归。
