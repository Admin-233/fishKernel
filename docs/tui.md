# TUI

`fishkernel tui AGENT` 连接存档控制面；`--snapshot --width 100 --height 30 --no-color`
生成固定大小快照，`--plain` 使用普通逐行显示。交互终端当前仅支持 Linux。

左栏显示人机对话，右栏显示完整事件。折行后再建立视口；滚动单位是实际显示行，
包括中文宽度和原文换行。阅读历史时新事件不拉回底部，缩放尽量保留相同消息位置。

| 操作 | 行为 |
|---|---|
| 空输入时 Up/Down | 滚动一个显示行 |
| PgUp/PgDn | 一屏显示行，保留一行重叠 |
| Home/End | 空输入时到头/到底；编辑时移动光标 |
| Tab | 切换滚动栏 |
| Enter | 发送消息或执行控制命令 |
| Ctrl-C / :q | 退出界面，不停止内核 |

支持 :pause、:resume、:stop、:wake、:restart、:delay 秒数。
状态显示生效思考模式和插件异常数量；详细故障在右栏事件及日志中查看。
长输入横向滚动与光标使用同一可见片段，ESC 等待短暂超时后可独立识别。
界面保留最多 50000 个事件，完整历史仍在存档中。
